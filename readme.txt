5. Responsive Design

The portfolio uses a responsive layout that adapts to different screen
sizes. On smaller screens, the header and hero section change from
horizontal layouts to vertical layouts, the project grid changes from
two columns to one column, and the navigation and buttons can wrap when
necessary.


6. Accessibility

The portfolio was tested using AChecker with WCAG 2.0 Level AA.

The accessibility checker reported:
- 0 known problems
- 0 likely problems
- 35 potential problems

The potential problems require human review rather than representing
confirmed accessibility errors. I reviewed the page and did not identify
any of them as errors requiring changes.

The profile image includes descriptive alt text, and semantic HTML
elements and a structured heading hierarchy are used throughout the
portfolio.
